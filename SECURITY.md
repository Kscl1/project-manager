# Security policy

project-manager is an alpha maintained by one person. Support is best effort, with no promised response time (see [Status](README.md#status)).

## Supported versions

Only the latest release and `main` get fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately: open the repository's **Security** tab and click **Report a vulnerability**. GitHub keeps the report visible only to you and the maintainer.

A useful report says:

- what the problem is and what an attacker could do with it,
- the steps or a small example that shows it,
- the version or commit you tested.

Once a fix is out, the advisory is published and credits you, unless you ask not to be named.
